# Bhavya Foundation — Institutional Context Map

This workspace is the living institutional brain of Bhavya Foundation.  
One agent reads the right files at the right moment. Folders carry structure; files carry state.

**Vision**: Building for Generations.  
**Missions**: Forest · Knowledge · Heritage · Community

Built on Interpretable Context Methodology (ICM). The structure is the documentation.

## Where things live

| Folder | What it holds |
|---|---|
| `corpus/` | Source-of-truth originals (Constitution, policies, Brand Constitution, Master PRD) |
| `governance/` | Founder, Board, charters as structured nodes |
| `pillars/` | Forest, Knowledge, Heritage, Community |
| `institutes/` | AI Lab, Digital Institute |
| `products/` | Content OS, GitOS (and future strategic products) |
| `knowledge-layer/` | Shared knowledge model & entities |
| `programmes/` | Concrete programmes under the missions |
| `policies/` | Operational policy nodes (link to corpus) |
| `brand/` | Brand Constitution + design system + assets |
| `teams/` | Organizational nodes |
| `_meta/` | Schema, rules, node types |
| `dashboards/` | Live queries / trackers |
| `patterns/` | Cross-mission patterns (bottom-up only) |

## Route by task

| If you need… | Go to | Then |
|---|---|---|
| Institutional overview | `CONTEXT.md` | stop |
| Constitutional text / legal source | `corpus/01_The_Constitution.md` etc. | read only what the question needs |
| Product & technology direction | `corpus/prd/Master_Product_Requirements_Document.md` | then institutes/ + products/ |
| Forest (Nature) work | `pillars/forest/CONTEXT.md` | programmes under it |
| Knowledge / AI / education | `pillars/knowledge/` → `institutes/ai-lab/` + `institutes/digital-institute/` | |
| Heritage | `pillars/heritage/CONTEXT.md` | |
| Community | `pillars/community/CONTEXT.md` | |
| Brand voice, logo, design system | `brand/CONTEXT.md` + `brand/assets/` | |
| Content production & publishing | `products/content-os/CONTEXT.md` | |
| Open-source intelligence / engineering | `products/gitos/CONTEXT.md` | |
| Shared knowledge model | `knowledge-layer/CONTEXT.md` | |
| Any policy | `policies/` then link to `corpus/` | |
| Status of structure | `FILE-MAP.md` | regenerate if stale |

## The one rule

Load only what the current step needs (2k–8k tokens healthy range).  
Never stuff the whole workspace.  
Nothing public-facing moves without human review of evidence and brand.
