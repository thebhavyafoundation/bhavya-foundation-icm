# GitOS

Internal institutional technology intelligence and engineering system.

**Mission**: Help Bhavya discover, understand, evaluate, integrate, operate, and evolve open-source technology that can strengthen its four missions.

GitOS is **not** a public-facing application.

## Pipeline
DISCOVER → INGEST → UNDERSTAND → ANALYSE → SECURITY REVIEW → LICENSE REVIEW → BENCHMARK → MISSION MATCH → SANDBOX → ADAPT → INTEGRATE → DOCUMENT → GOVERN

## Core Capabilities
- Open-source intelligence (architecture, dependencies, license, health, security, mission relevance)
- Mission Fit Scoring (Forest / Knowledge / Heritage / Community + security, license, maintenance, etc.)
- Skills Registry (reusable capabilities: OCR, RAG, GIS, transcription, local-LLM, browser automation, …)
- Harness Registry (agent frameworks, workflow engines, MCP ecosystems, local runtimes)
- Build-vs-Integrate decision enforcement
- Repository intelligence for Bhavya’s own codebases
- Institutional memory of technical decisions (ADR → implementation → evidence)

## Build vs Integrate Rule
Need identified → Search existing open source → Evaluate → Can we safely reuse?  
YES → Adapt · NO → Build  
Both paths register in GitOS.
